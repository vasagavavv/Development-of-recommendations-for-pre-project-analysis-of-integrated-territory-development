## Разработка рекомендаций для предпроектного анализа комплексного развития территории

### Описание

Данный метод предназначен для предпроектного анализа открытых городских общественных пространств в рамках разработки архитектурного проекта. В рамках метода генерируется система рекомендаций, которая использует матрицу по системе "дефицит - норма - профицит" и "важность - статус". Рекомендации подбираются на основе уже собранной базы данных по проектам в рамках всерос. конкурса "МГиИП".

### Используемые методы

1. Изохронный анализ доступности
2. Метод аналогов (k ближайших соседей)
3. Робастная нормализация

## Development-of-recommendations-for-pre-project-analysis-of-integrated-territory-development

### Description

This method is designed for pre-project analysis of urban open public spaces as part of architectural design development. It generates a recommendation system using a matrix based on the "deficit-norm-surplus" and "importance-status" systems. Recommendations are selected based on an already compiled database of projects submitted as part of the All-Russian competition for improvement projects for small towns and historic settlements.

### Used method

1. Isochronous availability analysis
2. Analog method (k-nearest neighbors)
3. Robust normalization
