## Разработка рекомендаций для предпроектного анализа комплексного развития территории
-----------------------------
### Описание

Данный метод предназначен для предпроектного анализа открытых городских общественных пространств в рамках разработки архитектурного проекта. 

По итогам его работы генерируется матрица рекомендаций по системе "дефицит - норма - профицит" и "важность - статус". 

Рекомендации подбираются на основе уже собранной и периодически обновляемой базы данных по проектам в рамках всерос. конкурса "МГиИП".

На данный момент (и всегда) метод будет заисеть от полноты БД OpenStreetMap и количества полезной информации в нем.
